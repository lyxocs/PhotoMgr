# PhotoMgr for iPhone

需要 iOS 17 或更新版本。App 直接读取系统照片图库，支持完整或有限访问权限。可以按拍摄日期浏览和筛选、查看近期拍摄的相似照片组、勾选照片以及只看已选。勾选用相册资源标识保存在手机上，重启后会恢复。

分组使用本地缩略图，在同一天内比较 12 秒内的照片。仅在 iCloud 且分组时无法取得本地缩略图的照片先单独显示，浏览时可按需从 iCloud 读取缩略图。照片无需导入电脑，第一版无需 TokenLink 密钥。

## 在 iPhone 上运行

1. 将本目录放到 Mac 上，用 Xcode 打开 PhotoMgr.xcodeproj。
2. 在 PhotoMgr target 的 Signing & Capabilities 中选择你的 Team。若包标识已被占用，改成你自己的 Bundle Identifier。
3. 连接 iPhone，在 Xcode 选择手机并点击 Run。若系统提示，按提示启用开发者模式。
4. 在 App 中允许访问照片。用拍摄日期筛选，点击缩略图勾选，打开「只看已勾选」核对结果。

## 真机验收

- 分别测试完整访问、有限访问和拒绝访问。
- 拍摄几张近似照片并重新扫描，确认按日期显示且能组成相似组。
- 勾选几张，退出并重新打开 App，确认勾选仍在。
- 测试仅存于 iCloud 的照片，确认可以按日期找到并按需查看缩略图。
